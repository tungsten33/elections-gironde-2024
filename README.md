# Observatoire des Élections Législatives 2024 en Gironde — Analyse du Découpage Électoral

Ce projet est une application web interactive dédiée à la compréhension de la géographie politique, des effets du redécoupage électoral (circonscriptions uninominales) et à la simulation de modes de scrutin alternatifs sur les résultats officiels des élections législatives de 2024 en Gironde (département 33).

L'application respecte les codes visuels institutionnels (style inspiré de la Société des Grands Projets, titres en *Times New Roman Italique*, cartographie Leaflet, tableaux interactifs et simulateur de scrutin en temps réel).

---

## 1. Fonctionnalités de l'Application

1. **Cartographie Interactive & Vue d'Ensemble 2024**
   - Visualisation des 12 circonscriptions de la Gironde.
   - 4 calques d'analyse : Députés élus, taux de participation au 1er tour, écart de victoire au 2nd tour (sièges bascules) et pénétration du vote Rassemblement National.
   - Fiche d'inspection dynamique par circonscription.

2. **Dossier Biais de Découpage (*Gerrymandering & Efficiency Gap*)**
   - Mesure de l'écart démographique entre circonscriptions (jusqu'à 36 820 habitants d'écart entre la 6e et la 11e circonscription).
   - Calcul de l'indice de disproportion de Gallagher (24,7 %).
   - Comparaison directe entre vote populaire du 1er tour et attribution finale des sièges.
   - Analyse du mécanisme de « Packing » (hyper-centre bordelais) et de « Cracking » (zones rurales et périurbaines).

3. **Simulateur de Scrutins en Temps Réel**
   - **Scrutin Réel 2024** : Uninominal à deux tours avec désistements républicains (NFP : 7, ENS : 4, RN : 1).
   - **Proportionnelle Intégrale (D'Hondt)** : Répartition mathématique des 12 sièges départementaux (RN : 4, NFP : 4, ENS : 4).
   - **Proportionnelle au Quota de Hare** (Plus Fort Reste).
   - **Proportionnelle avec Prime Majoritaire de 25%** (accordée à la liste arrivée en tête).
   - **Scrutin Majoritaire Sans Désistements** (simulation du maintien de 7 triangulaires au second tour).

4. **Laboratoire de Redécoupage Alternatif**
   - 3 scénarios territoriaux : Rééquilibrage démographique strict, Sanctuaire métropolitain vs ruralité, et Découpage indépendant non partisan.

5. **Explorateur de Données Ouvertes & Export CSV**
   - Filtres textuels et par sensibilité politique.
   - Export en un clic de l'intégralité du jeu de données au format CSV.
   - Connecteur d'API data.gouv.fr.

## 2. Déploiement Pas-à-Pas sur Netlify

### Méthode 1 : Déploiement Direct via GitHub (Recommandée)
1. **Créer un nouveau dépôt sur GitHub :**
   - Rendez-vous sur [github.com/new](https://github.com/new).
   - Nommez le dépôt (ex: `elections-gironde-2024`).
   - Laissez le dépôt en public ou privé et créez-le.

2. **Pousser les fichiers depuis votre terminal ou VS Code :**
   ```bash
   git init
   git add .
   git commit -m "feat: version initiale observatoire legislatives gironde 2024"
   git branch -M main
   git remote add origin https://github.com/VOTRE_NOM_UTILISATEUR/elections-gironde-2024.git
   git push -u origin main
   ```

3. **Lier le dépôt à Netlify :**
   - Connectez-vous sur [app.netlify.com](https://app.netlify.com).
   - Cliquez sur **« Add new site »** puis **« Import an existing project »**.
   - Choisissez **GitHub** et sélectionnez votre dépôt `elections-gironde-2024`.
   - Laissez les paramètres par défaut :
     - *Build command* : (laisser vide)
     - *Publish directory* : `.` (la racine)
   - Cliquez sur **« Deploy site »**. Votre application est en ligne en moins de 15 secondes avec certificat SSL gratuit.

### Méthode 2 : Glisser-Déposer (Netlify Drop)
- Allez sur [app.netlify.com/drop](https://app.netlify.com/drop).
- Glissez-déposez directement le dossier contenant `index.html`, `style.css`, `app.js` et `netlify.toml`.

## 3. Édition Locale avec Visual Studio Code

1. Ouvrez le dossier dans VS Code :
   ```bash
   code .
   ```
2. Installez l'extension recommandée **Live Server** (par Ritwick Dey).
3. Faites un clic droit sur `index.html` puis sélectionnez **« Open with Live Server »**.
4. Votre navigateur ouvrira l'application à l'adresse `http://127.0.0.1:5500`. Toute modification dans le code HTML, CSS ou JS sera rechargée automatiquement.

## 4. Connexion Optionnelle à Supabase

Si vous souhaitez enregistrer des simulations d'utilisateurs ou charger dynamiquement des cantons :
1. Créez un projet gratuit sur [supabase.com](https://supabase.com).
2. Dans la console SQL de Supabase, exécutez la création de table :
   ```sql
   create table gironde_simulations (
     id bigint generated by default as identity primary key,
     created_at timestamp with time zone default timezone('utc'::text, now()) not null,
     mode_scrutin text not null,
     seuil numeric default 5,
     resultats_sieges jsonb
   );
   ```
3. Dans `app.js`, renseignez les constantes :
   ```javascript
   const SUPABASE_CONFIG = {
       url: "https://xyzcompany.supabase.co",
       anonKey: "eyJhbGciOi...",
       isConfigured: true
   };
   ```

## 5. Sources des Données Publiques Utilisées

- **Ministère de l'Intérieur et des Outre-Mer** : Résultats définitifs du 1er et 2nd tour des élections législatives 2024 via `data.gouv.fr`.
- **INSEE** : Populations légales millésimées par circonscription législative.
- **Société des Grands Projets** : Charte graphique institutionnelle et palette chromatique minérale.
